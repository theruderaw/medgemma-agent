## Locked decisions

- SSE transport = native `EventSource` on `GET /v1/jobs/{id}/events`
  (free auto-reconnect + Last-Event-ID replay).
- Resilience: replay-first; fall back to `pollJob` only after repeated
  connection failures or a terminal `error` event.
- Triage opt-in = per-message toggle in ChatInput (off by default),
  threads `?triage=true`; matches backend semantics exactly.
- Emergency floor turns arrive synchronously (200) — render direct, never queue.
- Logs page shows the **audit trail** (Postgres `audit_events`) via a new
  read-only backend endpoint. Stack unchanged: React 19 + Vite + TS + Tailwind 4.
- Delete stale `static/index.html` prototype and `frontend/dist/`.
- `architecture.md` stays untouched (Rudra's call).
